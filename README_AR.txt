Life OS — نسخة Web App قابلة للتثبيت

محتويات الحزمة:
- index.html: التطبيق.
- manifest.webmanifest: بيانات التثبيت على الشاشة الرئيسية.
- sw.js: تشغيل الواجهة دون اتصال بعد أول زيارة.
- icon-192.png و icon-512.png: أيقونات التطبيق.

مهم:
1) يجب رفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة (مثل GitHub Pages).
2) بعد فتح رابط HTTPS على Android Chrome: القائمة ⋮ ثم "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".
3) البيانات تظل محلية على نفس المتصفح والجهاز، ولا تُرفع إلى الاستضافة.
4) استخدم "تصدير نسخة" من الإعدادات لعمل Backup دوري.
5) لا تمسح بيانات Chrome/الموقع قبل تصدير نسخة احتياطية.
